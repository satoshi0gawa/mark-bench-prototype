HOW_TO_USE

使い方

  1. テンプレートまたは行数・列数を選び、セル内容を入力します。
  2. 表計算ソフトの複数セルは、そのままセルへ貼り付けられます。
  3. 見出し・キャプション・整列と、色・罫線・余白・交互行を設定します。
  4. プレビューと警告を確認し、HTMLまたはCSSをコピーします。

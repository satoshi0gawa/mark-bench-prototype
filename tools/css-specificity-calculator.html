HOW_TO_USE

使い方

  1. 1行ごと、またはカンマ区切りでCSSセレクターを入力します。
  2. 各セレクターのA・B・C詳細度と構成要素を確認します。
  3. 必要に応じて詳細度の高い順へ並べ替えて比較します。
  4. COPY REPORTで計算結果をまとめてコピーします。

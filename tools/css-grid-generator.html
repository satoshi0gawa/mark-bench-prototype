  1. プリセットまたはSAMPLEからレイアウトを選択します。
  2. 列・行・gap・整列と自動配置を調整します。auto-fit／auto-fillでは最小列幅を指定します。

GRID NOTES / 2026.11.07

Gridの仕様と出力の範囲

repeat()・minmax()・fr・gapを使い、明示トラックと暗黙トラックの両方を出力します。セル内の配置と、トラック全体の配置は別の指定です。固定列数ではminmax(0, 1fr)で均等分割し、自動列では最小幅と利用できる横幅から列数を決定します。

Grid Level 2のsubgridは、子グリッドが親の行・列トラックを共有する仕組みです。このツールは単一コンテナの生成を対象とし、ネストしたsubgridは出力しません。Level 3のgrid lanes（masonry系）は草案・実験段階のため出力対象外です。

出力クラスはgrid-layout／grid-layout__itemです。プレビューの装飾は含めません。spanは先頭アイテムのみを対象とし、自動列では意図しない暗黙列を作らないよう列spanを1に制限します。

参考資料：WebToolBox Grid生成 ／ ICS MEDIA CSSグリッド入門。現行仕様：W3C Grid Level 2 ／ W3C Grid Level 3 ／ MDN repeat() ／ MDN Grid lanes。

OUTPUT_PATTERNS

選択パターン別の出力例

コード例の説明、シンタックスハイライト連携、横スクロールの必要性に合わせて選択します。迷った場合は、3項目すべてをONにした標準パターンを使用してください。

PATTERN 01

タイトルを空欄にすると、選択した言語名がキャプションになります。説明付きのコード例を掲載する基本形です。

<figure class="code-block">
  <figcaption class="code-block__caption">HTML</figcaption>
  <pre class="code-block__pre" tabindex="0"><code class="language-html">&lt;h2&gt;タイトル&lt;/h2&gt;</code></pre>
</figure>

短いコードを装飾や外部ハイライターなしで掲載する構成です。横スクロールが発生する可能性がある場合は、KEYBOARD SCROLLをONにします。

<pre class="code-block"><code>color: inherit;</code></pre>

HOW_TO_USE

使い方

  1. 掲載したいコードを入力または貼り付けます。
  2. HTML・CSS・SCSS・JavaScript・PHPから言語を選択します。
  3. キャプション、言語クラス、キーボードスクロールの設定とプレビューを確認します。
  4. COPY OUTPUTで生成されたHTMLをコピーします。

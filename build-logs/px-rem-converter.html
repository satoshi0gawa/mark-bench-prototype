pxとremの換算基準を整理する

pxとremの変換は単純な割り算と掛け算ですが、結果を正しく使うには基準となるルートフォントサイズと丸め方を共有する必要があります。双方向変換を安定させるための設計と検証内容を整理します。

01 / PURPOSE

換算ツールを作る理由

デザインデータではpx、CSSのタイポグラフィや余白ではremというように、Web制作では同じ寸法を異なる単位で扱う場面があります。値が少なければ暗算できますが、複数のサイズを確認しながら実装すると、割り算の基準や小数点以下の扱いが担当者ごとに変わりやすくなります。

PX / REM Converterでは、変換する数値とルートフォントサイズを明示し、計算結果と式を同じ画面で確認できる状態を目指しました。pxからremへ変換するだけでなく、remから元のpxへ戻す操作も同じ条件で行えるようにします。

PROCESS

入力値 → 変換方向を選択 → ルートフォントサイズを適用 → 丸め精度を反映 → 結果と計算式を表示

02 / ROOT SIZE

ルートサイズを基準にする

remはルート要素のフォントサイズを基準にした相対単位です。ブラウザの一般的な初期値である16pxを使う場合、16pxは1rem、32pxは2remになります。ただし、プロジェクト側でルートサイズを変更している場合は同じpx値でも結果が変わります。

そのため、ツールでは16pxを初期値としながら、1〜256pxの範囲で基準値を変更できるようにしました。変換結果だけでなく、現在使用しているルートサイズを画面へ常に表示し、どの条件で算出した値かを見失わない構成にしています。

DESIGN NOTE

remは固定の換算表ではありません。ルートフォントサイズを変換条件の一部として扱うことで、プロジェクトごとの設計基準に合わせられます。

03 / FORMULA

双方向の計算式を揃える

pxからremへ変換するときは入力値をルートサイズで割り、remからpxへ戻すときはルートサイズを掛けます。変換方向によって入力欄の単位表示と演算子を切り替え、結果には必ず出力単位を付けます。

const numericResult = direction === 'rem-to-px'
  ? inputValue * rootSize
  : inputValue / rootSize;

// root size: 16px
32px ÷ 16px = 2rem
2rem × 16px = 32px

結果の数値だけでなく、32px ÷ 16px = 2remのように式も表示します。入力値、基準値、演算方向を一度に確認できるため、別のプロジェクトへ値を移すときも換算条件を追いやすくなります。

04 / PRECISION

丸め精度を選べるようにする

pxをremへ変換すると、割り切れない小数が発生します。用途によって必要な精度が異なるため、不要な末尾の0を除くAUTO、小数点以下を2桁に揃える2 DEC、4桁に揃える4 DECの3種類を用意しました。

const formatNumber = (value, precision) => {
  const normalized = Object.is(value, -0) ? 0 : value;
  if (precision === '2') return normalized.toFixed(2);
  if (precision === '4') return normalized.toFixed(4);
  return String(Number(normalized.toFixed(6)));
};

AUTOでは内部計算の長い小数を最大6桁で整理してから、不要な末尾の0を取り除きます。また、計算過程で発生する可能性がある-0は0へ正規化し、コピー後も扱いやすい出力にします。

05 / VALIDATION

入力値と状態表示を検証する

入力値は正負どちらにも対応し、絶対値1,000,000までを有効範囲としました。ルートフォントサイズは1〜256pxに制限し、空欄、数値以外、範囲外の値をそれぞれ判定します。無効な場合は結果を「—」へ戻し、コピーボタンを操作できない状態にします。

画面にはINPUT EMPTY、READY、INVALID VALUE、ROOT SIZE OUT OF RANGEを表示し、該当する入力欄へaria-invalidを設定します。SAMPLE、CLEAR、変換方向、精度の変更後も同じ描画処理を通し、表示と内部結果がずれないことを確認しました。

06 / RESULT

実装から得た判断

計算ロジックと画面更新を分離したことで、変換方向や精度が変わっても同じ検証結果を利用できるようになりました。結果へ単位を含め、計算式を併記することで、単なる数値だけを返すよりも変換条件を確認しやすくなっています。

一方、remを採用すれば自動的に読みやすくなるわけではありません。タイポグラフィ、余白、コンポーネント寸法のどこへ相対単位を使うかは、サイト全体の設計ルールとして決める必要があります。このツールは、その判断に必要な換算を素早く確かめるための補助として位置づけています。

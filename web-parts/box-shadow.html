BOX SHADOW

カード、操作ボタン、選択状態、暗色セクションで、面の高さ・方向・輪郭・凹みを伝えるbox-shadow表現10パターンです。

SOFT LAYERS

多層ソフト影

SURFACE
HTML

  <strong class="c-shadow__label">SOFT SURFACE</strong>
  <span class="c-shadow__text">カード本文</span>
</button>

  box-shadow:
    0 .15rem .3rem rgb(24 36 59 / 5%),

INTERACTIVE LIFT

ホバーリフト

ACTIONABLE SURFACE
HTML
<button class="c-shadow c-shadow--lift" type="button">
  <strong class="c-shadow__label">VIEW DETAILS</strong>
  <span class="c-shadow__text">詳細を見る</span>
</button>
CSS
.c-shadow--lift {
  box-shadow: 0 .35rem .8rem rgb(24 36 59 / 10%);
  transition: transform .25s ease, box-shadow .25s ease;
}
.c-shadow--lift:focus-visible {
  transform: translateY(-.35rem);
  box-shadow: 0 1.2rem 2rem rgb(24 36 59 / 20%);
}
.c-shadow--lift:active {
  transform: translateY(.08rem);
  box-shadow: 0 .2rem .45rem rgb(24 36 59 / 14%);
}
@media (hover: hover) and (pointer: fine) {
  .c-shadow--lift:hover:not(:active) {
    transform: translateY(-.35rem);
    box-shadow: 0 1.2rem 2rem rgb(24 36 59 / 20%);
  }
}
@media (prefers-reduced-motion: reduce) {
  .c-shadow--lift { transition: none; }
}
USE FOR

記事・商品カードやダッシュボードの操作面で、クリック可能であることを影と移動量の変化で伝える場面。

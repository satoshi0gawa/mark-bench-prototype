HEADING

ページタイトルや記事・セクションの区切りで情報階層を明確にする、見出し表現16パターンです。

PATTERNS: 16TYPE: CSSDEPENDENCY: NONE
COMMON STYLE↓

KEYWORDS

UNDERLINE

下線アクセント

ONE LINE

見出しサンプル

HTML
<h2 class="c-heading c-heading--underline">
  見出しサンプル
</h2>
CSS
.c-heading--underline {
  display: inline-block;
  padding-bottom: .45rem;
  border-bottom: 4px solid
    var(--color-primary, #18243b);
}
USE FOR

本文中の小見出しなど、装飾を抑えながら階層を明確にしたい場面。

TOAST

保存・送信結果、エラー、通信状態などを作業の流れを止めずに伝える、Vanilla JavaScript対応のトースト通知12パターンです。

PATTERNS: 12TYPE: CSS + JSDEPENDENCY: NONE

BASIC

ベーシック

AUTO DISMISS
HTML
<div class="c-toast" data-toast data-duration="3000">
  <button class="c-toast__trigger" type="button">表示する</button>
  <div class="c-toast__region" aria-live="polite"></div>
</div>
CSS
.c-toast { position: relative; min-height: 10rem; text-align: center; }
.c-toast__trigger { padding: .65rem 1rem; color: #fff; background: var(--color-primary, #18243b); border: 0; cursor: pointer; }
.c-toast__region { position: absolute; right: 0; bottom: 0; left: 0; display: grid; place-items: center; pointer-events: none; }
.c-toast__item { padding: .75rem 1rem; color: #fff; background: var(--color-primary, #18243b); opacity: 0; transform: translateY(.75rem); transition: .24s; }
.c-toast__item.is-visible { opacity: 1; transform: none; }
JAVASCRIPT
document.querySelectorAll('[data-toast]').forEach((root) => {
  const region = root.querySelector('.c-toast__region');
  const trigger = root.querySelector('.c-toast__trigger');
  trigger.addEventListener('click', () => {
    trigger.disabled = true;
    region.replaceChildren();
    const item = document.createElement('div');
    item.className = 'c-toast__item';
    item.textContent = '保存しました';
    region.append(item);
    requestAnimationFrame(() => item.classList.add('is-visible'));
    setTimeout(() => {
      item.classList.remove('is-visible');
      setTimeout(() => { item.remove(); trigger.disabled = false; }, 250);
    }, Number(root.dataset.duration) || 3000);
  });
});
USE FOR

保存や更新など、短い完了メッセージ。通常の結果通知は控えめな読み上げにします。

JAVASCRIPT
const root = document.querySelector('[data-consent-toast]');
const region = root.querySelector('.c-toast__region');
const key = 'site-cookie-consent';
const reset = root.querySelector('[data-reset]');
function show() {
  reset.disabled = true;
  const item = document.createElement('div');
  item.className = 'c-toast__item';
  item.innerHTML = '<span>当サイトではCookieを使用します。</span><button type="button">同意する</button>';
  region.replaceChildren(item);
  item.querySelector('button').addEventListener('click', () => {
    localStorage.setItem(key, '1');
    item.remove();
    reset.disabled = false;
  });
}
reset.addEventListener('click', () => { localStorage.removeItem(key); show(); });
if (localStorage.getItem(key) !== '1') show();
USE FOR

Cookie利用の案内。法的な同意要件がある場合は専用CMPの利用も検討します。

const root = document.querySelector('[data-status-toast]');
const region = root.querySelector('.c-toast__region');
const messages = { success: '保存しました', error: 'エラーが発生しました', warning: '入力をご確認ください', info: 'お知らせがあります' };
const buttons = [...root.querySelectorAll('[data-tone]')];
buttons.forEach((button) => {
  button.addEventListener('click', () => {
    let item = region.querySelector('.c-toast__item');
    const isNew = !item;
    if (isNew) {
      item = document.createElement('div');
      item.className = 'c-toast__item';
      region.append(item);
    }
    clearTimeout(Number(item.dataset.timer));
    item.dataset.tone = button.dataset.tone;
    item.textContent = messages[button.dataset.tone];
    if (button.dataset.tone === 'error') item.setAttribute('role', 'alert');
    else item.removeAttribute('role');
    if (isNew) requestAnimationFrame(() => item.classList.add('is-visible'));
    item.dataset.timer = setTimeout(() => item.remove(), 3000);
  });
});
USE FOR

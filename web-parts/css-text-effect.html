CSS-TEXT-EFFECT

キービジュアルやキャンペーン見出しで、光・色・奥行き・動きを使って文字へ視線を集めるCSSテキストエフェクト12パターンです。

NEON

ネオン発光

GLOW LOOP
NEON SIGNAL
HTML
<span class="c-text-effect c-text-effect--neon">
  NEON SIGNAL
</span>
CSS
.c-text-effect--neon {
  color: var(--color-text-inverse, #fff);
  text-shadow:
    0 0 .3rem var(--color-focus, #315a9b),
    0 0 .8rem var(--color-focus, #315a9b),
    0 0 1.5rem var(--color-focus, #315a9b);
  animation: c-text-effect-neon 1.8s ease-in-out infinite alternate;
}
@keyframes c-text-effect-neon {
  from { text-shadow: 0 0 .2rem var(--color-focus, #315a9b),
    0 0 .55rem var(--color-focus, #315a9b); }
  to { text-shadow: 0 0 .45rem var(--color-focus, #315a9b),
    0 0 1rem var(--color-focus, #315a9b),
    0 0 1.8rem var(--color-accent-yellow, #ff0); }
}
USE FOR

夜間イベントや配信画面など、暗い面の上で短いメッセージを強く見せる場面。

SLIDER / Splide

ファーストビュー、実績一覧、画像ギャラリー、重要メッセージなど、複数の情報を自動再生と手動操作の両方で届けるSplide対応スライダー4パターンです。

PATTERNS: 04TYPE: CSS + JSDEPENDENCY: Splide 4.1.4
COMMON STYLE↓

KEYWORDS

DISPLAY: 04 / 04

BASIC / 01

メッセージスライド

MESSAGE SLIDE

  • 01 / DESIGN

    役割から順序を決める

    一枚に一つの要点を置き、前後の流れまで含めて構成します。

  • 02 / OPERATION

    自動でも操作を残す

    再生中も矢印・ページ選択・停止から、閲覧ペースを選べます。

  • 03 / ACCESSIBILITY

    動きを止めても伝える

    動きを抑える設定でも、見出しと順序だけで内容を追えるようにします。

      MOTION / 01

      フェードストーリー

      FADE + PROGRESS

      • VISUAL HIERARCHY

        主役を一枚に絞る

        見出しと要点を同じ位置に保ち、切り替わっても視線を迷わせません。

      • READABILITY

        文字の読みやすさを守る

        背景が変わっても、色と余白で必要なコントラストを確保します。

      • MOTION CONTROL

        速度と停止条件を整える

        自動再生と手動操作が競合しない、穏やかな切り替えにします。

      const root = document.querySelector('#fade-slider');
const progress = root.querySelector('.c-splide-progress');
const bar = progress.querySelector('span');
const reduceMotion = matchMedia('(prefers-reduced-motion: reduce)').matches;
const slider = new Splide(root, {
  type: 'fade', rewind: true, autoplay: !reduceMotion,
  interval: 5200, speed: reduceMotion ? 0 : 900,
  pauseOnHover: true, pauseOnFocus: true,
  keyboard: 'focused', pagination: false,
});
const update = () => {
  const current = slider.index + 1;
  progress.setAttribute('aria-valuenow', String(current));
  bar.style.transform = `scaleX(${current / slider.length})`;
};
slider.on('mounted moved', update);
slider.mount();

SCROLL-REVEAL

記事一覧、特集、サービス紹介などで、要素が表示領域へ入るタイミングに合わせて情報を段階的に提示する、Vanilla JavaScript対応のスクロール演出12パターンです。

FADE UP

フェードアップ

BASIC
SCROLL DOWN
↓ SCROLL
次の情報を表示
HTML
<section class="c-scroll-reveal c-scroll-reveal--fade-up"
  data-reveal-fade>
  次の情報を表示
</section>
CSS
.c-scroll-reveal--fade-up {
  transform: translateY(2rem);
}
.c-scroll-reveal--fade-up.is-revealed {
  opacity: 1;
  transform: none;
}
JAVASCRIPT
const target = document.querySelector('[data-reveal-fade]');
const observer = new IntersectionObserver(([entry]) => {
  target.classList.toggle('is-revealed', entry.isIntersecting);
}, { threshold: .35 });
observer.observe(target);
USE FOR

記事カードや補足情報を、読み進める流れに沿って静かに提示する場面。

JAVASCRIPT
const target = document.querySelector('[data-repeat-reveal]');
const toggle = document.querySelector('[data-repeat-toggle]');
const observer = new IntersectionObserver(([entry]) => {

}, { threshold: .35 });
observer.observe(target);

JAVASCRIPT
const figure = document.querySelector('[data-lazy-reveal]');
const image = figure.querySelector('img[data-src]');
const observer = new IntersectionObserver(([entry]) => {
  if (!entry.isIntersecting) return;
  image.src = image.dataset.src;
  image.addEventListener('load', () => figure.classList.add('is-loaded'), { once: true });
  observer.unobserve(figure);
}, { rootMargin: '160px' });
observer.observe(figure);

CSS
.c-scroll-parallax { position: relative; min-height: 9.5rem; overflow: hidden; }
.c-scroll-parallax__shape {
  position: absolute; aspect-ratio: 1; border-radius: 50%;
  background: var(--color-focus, #315a9b); will-change: transform;
}
.c-scroll-parallax__shape--a { top: -1rem; left: 6%; width: 4.5rem; opacity: .18; }
.c-scroll-parallax__shape--b { top: 1.4rem; right: 10%; width: 2.9rem; opacity: .3; }
.c-scroll-parallax__shape--c { bottom: -.2rem; left: 34%; width: 1.7rem; opacity: .48; }
.c-scroll-parallax__caption { position: relative; z-index: 1; text-align: center; }
JAVASCRIPT
const root = document.querySelector('[data-parallax]');
const items = root.querySelectorAll('[data-speed]');
let frame = 0;
const render = () => {
  frame = 0;
  const rect = root.getBoundingClientRect();
  const delta = rect.top + rect.height / 2 - innerHeight / 2;
  items.forEach((item) => {
    item.style.transform = `translateY(${(delta * Number(item.dataset.speed)).toFixed(1)}px)`;
  });
};
addEventListener('scroll', () => { if (!frame) frame = requestAnimationFrame(render); }, { passive: true });
render();
USE FOR

キービジュアルや背景装飾へ小さな奥行きを加え、本文の可読性を保ちたい場面。

const sections = root.querySelectorAll('[data-morph-color]');
const observer = new IntersectionObserver((entries) => {

    if (entry.isIntersecting) root.style.setProperty('--morph-color', entry.target.dataset.morphColor);
  });
}, { threshold: .6 });
sections.forEach((section) => observer.observe(section));

  position: absolute; top: 0; left: .55rem; width: 3px;
  height: var(--timeline-progress); background: #315a9b;
}
.c-scroll-timeline__step.is-active { color: #1c2430; }
JAVASCRIPT
const timeline = document.querySelector('[data-timeline]');
const steps = [...timeline.querySelectorAll('.c-scroll-timeline__step')];
const update = () => {
  const rect = timeline.getBoundingClientRect();
  const ratio = Math.max(0, Math.min(1, (innerHeight - rect.top) / (innerHeight + rect.height)));
  timeline.style.setProperty('--timeline-progress', `${ratio * 100}%`);
  steps.forEach((step, index) => step.classList.toggle('is-active', ratio >= index / steps.length));
};
addEventListener('scroll', update, { passive: true });
update();
USE FOR

沿革、制作工程、導入手順など、現在までの進み具合と残りを同時に示す場面。

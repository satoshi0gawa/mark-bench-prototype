GLASS

写真やグラデーション背景の上で、情報パネル、暗色カード、固定ナビゲーション、検索フォームに透過とぼかしの層を加えるグラスモーフィズム4パターンです。

DISPLAY: 04 / 04

FROSTED PANEL

フロストパネル

LIGHT SURFACE

PROJECT NOTE

背景の色を残しながら、本文を読み取れる面を作ります。

HTML
<article class="c-glass c-glass--frost">
  <h3 class="c-glass__title">PROJECT NOTE</h3>
  <p class="c-glass__text">パネル本文</p>
</article>
CSS
.c-glass--frost {
  color: var(--color-primary, #18243b);
  background: rgb(255 255 255 / 30%);
  border: 1px solid rgb(255 255 255 / 68%);
  backdrop-filter: blur(18px) saturate(135%);
  -webkit-backdrop-filter: blur(18px) saturate(135%);
}
.c-glass--frost .c-glass__text {
  color: rgb(24 36 59 / 82%);
}
USE FOR

写真やグラデーションを見せながら、紹介文や要点を読みやすい面へまとめる場面。

DARK GLASS

ダークグラス

DARK SURFACE

NIGHT MODE

明るい背景要素を抑え、白文字の情報へ視線を集めます。

HTML
<article class="c-glass c-glass--dark">
  <h3 class="c-glass__title">NIGHT MODE</h3>
  <p class="c-glass__text">パネル本文</p>
</article>
CSS
.c-glass--dark {
  color: var(--color-text-inverse, #fff);
  background: rgb(24 36 59 / 58%);
  border: 1px solid rgb(255 255 255 / 20%);
  backdrop-filter: blur(20px) saturate(125%);
  -webkit-backdrop-filter: blur(20px) saturate(125%);
}
.c-glass--dark .c-glass__text {
  color: rgb(255 255 255 / 82%);
}
USE FOR

キービジュアル、動画、夜景など明暗差の大きい背景上で、白文字の情報を安定して提示する場面。

LOADING

フォーム送信、データ取得、画面遷移などの待ち時間に、処理中であることを伝えるCSSローディング表現14パターンです。

PATTERNS: 14TYPE: CSSDEPENDENCY: NONE

KEYWORDS

BASIC / 01

スピナー

SINGLE RING
HTML
<div class="c-loading c-loading--spinner"
  role="status" aria-label="読み込み中"></div>
CSS
.c-loading--spinner {
  display: grid; min-height: 6rem; place-items: center;
}
.c-loading--spinner::before {
  width: 3rem; height: 3rem; border: .3rem solid #edf1f7;
  border-top-color: var(--color-primary, #18243b);
  border-radius: 50%; content: "";
  animation: loading-spin .85s linear infinite;
}
@keyframes loading-spin { to { transform: rotate(360deg); } }
@media (prefers-reduced-motion: reduce) {
  .c-loading--spinner::before { animation: none; }
}
USE FOR

送信や通信など、完了までの時間を予測できない短い待機状態。

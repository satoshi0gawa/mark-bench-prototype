WEB_PARTS / BUTTON

BUTTON

フォーム送信や購入・遷移などの主要操作と、キャンセル・状態表示・危険操作に使い分けられるボタン16パターンです。

PATTERNS: 16TYPE: CSSDEPENDENCY: NONE
COMMON STYLE↓

KEYWORDS

DISPLAY: 16 / 16

GRADIENT

グラデーション

PRIMARY CTA
HTML
<button class="c-button c-button--gradient" type="button">
  送信する
</button>
CSS
.c-button--gradient {
  color: var(--color-text-inverse, #fff);
  background: linear-gradient(120deg,
    var(--color-primary, #18243b),
    var(--color-primary-hover, #263a5e));
  box-shadow: 0 .6rem 1.3rem rgb(24 36 59 / .25);
}
.c-button--gradient:hover {
  transform: translateY(-.2rem);
}
USE FOR

送信や申し込みなど、画面内で最も優先度の高いCTAを明確にする場面。

PHOTOSHOP_HOUSING_LP

Photoshopカンプから住宅会社LPを実装した記録

Photoshopのカンプには、特定の画面幅での写真の見え方や文字の位置が示されています。
Webページとして再現するには、画面幅が変わったときに何を保ち、何を変えるかも決める必要があります。
架空の住宅会社「酒田工務店」のLPを題材に、カンプから読み取った見た目をHTML、CSS、JavaScriptへどう落とし込んだかをまとめます。

01 / OVERVIEW

制作概要

酒田工務店は、住宅の写真、家づくりのコンセプト、6件の施工実績、お知らせ、問い合わせ案内を1ページで紹介する制作デモです。
デイトラの有料教材「Photoshopのデザインカンプからコーディング」で提供されたカンプをもとに、フロントエンドのコーディングを担当しました。

02 / PURPOSE & REQUIREMENTS

目的と要件

写真の構図と文字の読みやすさを保ちながら、PCとスマートフォンのカンプの違いを一つのHTMLで表現することが演習の中心です。
写真に重なるコピーもブラウザ上のテキストとして扱い、画面幅に応じて折り返しや文字サイズを調整できるようにしました。
スマートフォンでは、メニューを開いて目的のセクションに移動できるようにしています。

03 / SCOPE

担当範囲

担当は、見出しやナビゲーションのマークアップ、CSSによる配色・余白・レイアウトの再現、PC／SP画像の出し分け、JavaScriptによるメニューの開閉とフォーカス管理です。
Photoshopカンプはデイトラの教材提供です。
実装対象はHOMEの1ページで、会社概要やFAQなどの下層ページ、問い合わせの送信処理は対象外です。

04 / SITE STRUCTURE

サイト・ページ構成

サイト・ページ構成

下層ページや問い合わせ処理に相当する一部リンクはデモのHOMEへ戻り、リンクの読み上げ名でもその行き先を伝えています。

06 / IMPLEMENTATION

主要な実装ポイント

写真とテキストを分けて、構図を切り替える

カンプ上で重なっている写真とコピーを、picture とHTMLの見出し・段落に分けました。
写真は画面幅に応じて source の候補と img の既定画像を切り替えます。
ヒーローだけでなく、コンセプトと施工実績にもこの方法を使い、写真の見せ方と文字の折り返しを個別に調整できるようにしました。

情報が収まる幅で、お知らせと問い合わせ欄を再配置する

施工実績のカード列数はビューポート幅に応じて調整します。
一方、お知らせと問い合わせ欄は各セクションの幅をコンテナクエリで参照しています。
お知らせは幅が取れると日付・区分・本文が横に並び、幅が狭いと日付・区分の下に本文が続きます。

メニューの見た目と操作状態を同期する

狭い画面ではメニューを dialog のモーダルとして表示します。
開くとトリガーの aria-expanded を更新し、閉じるボタンへフォーカスを移します。
開いている間は背景のスクロール位置を保存して固定し、終了時に位置と元のスタイルを戻します。
Escapeで閉じた場合は開いたボタンに、ページ内リンクを選んだ場合は遷移先の見出しにフォーカスを移します。

レスポンシブとアクセシビリティ

レスポンシブとアクセシビリティ
切り替え条件対象

ビューポート 64rem 以上コンセプトのPC用画像と写真・本文の配置

ダイアログ内ではTabとShift+Tabでフォーカスを巡回でき、閉じた後は操作の流れに合う位置へ移動します。
:focus-visible でキーボード操作時の輪郭を表示し、動きを抑える設定ではメニューのフェードを省略します。
ダイアログを初期化できない場合は、ヘッダーのリンクを残します。

08 / PROBLEM & SOLUTION

課題と解決

  1. 01課題

    Photoshopカンプの文字サイズ、行間、要素間の距離をどうCSSへ置き換え、どこまでを画像として用意するかを判断する必要がありました。

  2. 02原因

    カンプ上の寸法は特定の画面幅に対応する値です。
    また、写真とコピーが見た目上は一体でも、画面幅が変わったときに必要な調整はそれぞれ異なります。

  3. 03解決

    文字サイズ・行間・余白はレイアウトを組む基準として読み取り、文字はHTML、配置はCSSで再現しました。
    写真はPCとSPで見せたい範囲を比べ、構図が異なるものを用途別の画像として用意しました。

  4. 04結果

    ヒーローは幅に応じて別の構図に切り替わり、コピーの折り返しやサイズはブラウザ上で調整できるようになりました。
    この実装をきっかけに、カンプの数値の読み取り、レイヤーの重なり、画像の書き出し範囲を学び直し、DESIGN WORKFLOWの「Web制作で使うPhotoshop TIPS」にまとめました。

09 / REVIEW & DELIVERY

検証と公開

PC用とSP用の画面でヒーロー画像の切り替えを確認し、メニューを構成するJavaScript 2ファイルは構文チェックを通過しました。
公開デモは認証前にHTTP 401、閲覧用のBasic認証後にHTTP 200となることを確認しました。
公開HTMLには noindex,nofollow が設定されています。

住宅会社、施工実績、お知らせ、連絡先は架空の内容です。
資料請求・メール・電話の案内は操作を示すための表示で、送信、電話発信、購入、資料配布は行いません。

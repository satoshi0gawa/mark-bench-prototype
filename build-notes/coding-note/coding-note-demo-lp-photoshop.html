【Photoshopデザインカンプ】コーディング演習 / 住宅会社向け LP

Photoshopのカンプには、特定の画面幅での写真の見え方や文字の位置が示されています。
Webページとして再現するには、画面幅が変わったときに何を保ち、何を変えるかも考える必要があります。
架空の住宅会社「酒田工務店」のLPを題材に、カンプをWebページにするための実装と、制作を振り返る際の学習ポイントを整理します。

01 / OVERVIEW

制作概要

酒田工務店は、住宅の写真、家づくりのコンセプト、6件の施工実績、お知らせ、問い合わせ案内を1ページで紹介する制作デモです。
デイトラの教材で提供されたPhotoshopカンプをもとにしたコーディング演習で、写真と文字を画面幅に合わせて表示する方法を扱います。

02 / PURPOSE & REQUIREMENTS

目的と要件

写真の構図と文字の読みやすさを保ちながら、PCとスマートフォンのカンプの違いを一つのHTMLで表現することが演習の中心です。
写真に重なるコピーはHTMLのテキストとして扱い、画面幅に応じて折り返しや文字サイズを調整できる構成です。
スマートフォンでは、メニューを経由して目的のセクションへ移動する構成を採用しています。

03 / SCOPE

担当範囲

Photoshopカンプはデイトラの教材で提供されたものです。
演習の対象はHOMEの1ページで、見出しやナビゲーションのマークアップ、CSSでの見た目の再現、PC／SP画像の出し分け、メニューの開閉とフォーカス管理を扱います。
会社概要やFAQなどの下層ページ、問い合わせの送信処理は演習の対象外です。

04 / SITE STRUCTURE

サイト・ページ構成

サイト・ページ構成
セクション役割
HERO住宅の写真とコピーで、ページの第一印象を伝える
CONCEPT写真と文章で、住宅づくりの考え方を紹介する

ヘッダーとフッターの主要リンクはページ内の該当セクションへ移動します。
下層ページや問い合わせ処理に相当する一部リンクはデモのHOMEへ戻り、リンクの読み上げ名でもその行き先を伝えています。

06 / IMPLEMENTATION

主要な実装ポイント

写真とテキストを分けて、構図を切り替える

カンプ上で重なっている写真とコピーは、picture とHTMLの見出し・段落に分けた構成です。
ブラウザは画面幅などの条件に応じて source の画像候補を選び、適用できる候補がなければ img の既定画像を使います。
ヒーロー、コンセプト、施工実績にこの方法を使い、写真の構図と文字の折り返しを個別に調整できる構成です。

お知らせ欄の幅に合わせて、日付・区分と本文を並べる

施工実績のカード列数はビューポート幅を基準に切り替わります。
お知らせ欄のレイアウトは、コンテナクエリでお知らせ欄自体の幅を参照する構成です。
幅が広いと日付・区分と本文が横に並び、狭いと日付・区分の下に本文が続きます。

メニューの見た目と操作状態を同期する

狭い画面ではメニューを dialog のモーダルとして表示します。
開くとトリガーの aria-expanded を更新し、閉じるボタンへフォーカスを移します。
開いている間は背景のスクロール位置を保存して固定し、終了時に位置と元のスタイルを戻します。
Escapeで閉じた場合は開いたボタンに、ページ内リンクを選んだ場合は遷移先の見出しにフォーカスを移します。

メニューは :focus-visible でフォーカスの輪郭を表示し、動きを抑える設定ではフェードを省略する構成です。
ダイアログを初期化できない場合に備え、ヘッダーにはセクションへ移動するリンクを用意しています。
TabとShift+Tabでの移動や、閉じた後のフォーカス位置は、実際のキーボード操作で確認する項目です。

08 / PROBLEM & SOLUTION

課題と解決

  1. 01課題

    Photoshopカンプの文字サイズ、行間、要素間の距離をどうCSSへ置き換え、どこまでを画像として用意するかを判断する必要がありました。

  2. 02原因

    カンプ上の寸法は特定の画面幅に対応する値です。
    また、写真とコピーが見た目上は一体でも、画面幅が変わったときに必要な調整はそれぞれ異なります。

  3. 03解決

    文字サイズ・行間・余白をレイアウトの基準とし、文字をHTML、配置をCSSで表現する構成です。
    構図が異なる写真は、PC用とSP用の画像を表示条件に応じて選びます。

  4. 04結果

    ヒーローは画面幅に応じて構図を切り替え、コピーの折り返しやサイズを別に調整できる構成です。
    カンプの数値の読み取り、レイヤーの重なり、画像の書き出し範囲が、制作を振り返る際の学習ポイントです。

09 / REVIEW & DELIVERY

検証と公開

公開デモにはBasic認証があります。
2026年11月14日に、認証情報を付けないHEADリクエストでHTTP 401を確認しました。

表示・操作と公開設定の確認項目

  • PCとスマートフォンの表示幅で、ヒーローなどに選ばれる画像とコピーの折り返し。
  • メニューを構成するJavaScriptファイルの構文。
  • Tab・Shift+Tabでの移動、Escapeやページ内リンクを使った後のフォーカス位置、動きを抑える設定での表示。
  • 認証後のHTTP応答と公開HTMLにおける noindex,nofollow の有無。

住宅会社、施工実績、お知らせ、連絡先は架空の内容です。
資料請求・メール・電話の案内は操作を示すための表示で、送信、電話発信、購入、資料配布は行いません。

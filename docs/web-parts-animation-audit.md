# WEB PARTS アニメーション開始処理の点検

2026-11-10時点の一覧36カテゴリを対象に、実際に読み込むJavaScript、CSSの有限アニメーション、初期化時のクラス変更、掲載コードを確認した。以下はコード調査の範囲であり、全434デモを実ブラウザで操作したという意味ではない。

## 修正対象

| ページ | 対象・問題 | 対応 |
| --- | --- | --- |
| COUNTER | 数値カウントアップ、カンマ区切り、円形プログレス、数字ロール。実デモの監視は交差率をコールバック内で検査しておらず、初回通知で端にわずかに触れただけでも開始できた。掲載コードは4例とも読み込み直後に再生していた | デモ自体の交差率35%以上、画面下端を10%縮めた領域で初回のみ開始。再生時刻は開始時に採り直す。REPLAYは維持し、数字ロールの残留タイマーを解除。動きを減らす設定では即時に最終値を表示。4例のHTML・CSS・JavaScriptを実デモに同期 |
| SCROLL-REVEAL | フェードアップ、左右スライド、ズーム、順番、ブラー、一度／毎回切替、行表示、画像遅延、カーテン。内部スクロール要素を監視のrootに指定していたため、ページ全体で画面外でも内部の交差だけで発火し得た | rootを省略し、ブラウザ表示領域と途中のスクロールコンテナの両方によるクリップを反映。交差率45%以上で表示。ONCEのREPLAYで監視を再登録。画像は画面内到達後に読み込み、キャッシュ済み画像にも対応。動きを減らす設定・監視非対応時は完成表示。9例の掲載コードを同じデモ構成・処理に同期 |
| TEXT-EFFECT | 先行修正済みの初回表示6種 | 今回は変更なし。既存の`check:text-effect`で回帰確認 |

SCROLL-REVEALの背景色モーフも監視をブラウザ表示領域基準に揃えた。内部スクロールに連動するパララックス・タイムラインは、再生して完了する演出ではないため開始時刻の変更対象にしない。

Intersection Observerは初回の監視登録時にも通知するため、`isIntersecting`だけでなく必要な交差率も確認する。rootを省略すると表示領域を基準にし、途中のスクロールコンテナによるクリップも考慮される。[MDN: Intersection Observer API](https://developer.mozilla.org/ja/docs/Web/API/Intersection_Observer_API)

## その他の確認結果

| 分類 | ページ | 結果 |
| --- | --- | --- |
| 操作を起点とする有限演出 | BUTTON、FORM、HAMBURGER MENU、ACCORDION、MODAL、TAB、DROPDOWN、PAGINATION、FEEDBACK、TOAST、UTILITY SCRIPT、CLIPBOARD、HOVER、MOTION、CLICK-EFFECTS | クリック・入力・開閉・hover等から開始。初期化だけで画面外の一回限りの演出が完了する処理は見つからなかった |
| 繰り返し再生 | LOADING、BADGE、SLIDER / Splide、SLIDER、CSS-TEXT-EFFECT、BACKGROUND-EFFECT | ループする演出・自動送りであり、到達前に終了する有限演出には該当しない。操作起点の部分も維持 |
| 静的表示・CSSによる操作状態 | HEADING、CARD、LIST、CSS-FORM、TABLE、BREADCRUMB、ALERT、TOOL-TIP、DIVIDER、BOX SHADOW、BACKGROUND PATTERN、GLASS | 読み込み時に始まり画面外で完了する有限アニメーションは見つからなかった |

COUNTERの時計・営業時間・経過日数・期限カウントダウンは、閲覧位置と無関係な時刻／期間の情報として更新を維持する。ストップウォッチは開始ボタンで動作し、タイプライターは繰り返すため対象外。

## 検証

- `npm run check:parts-viewport`は、画面外待機、交差率の境界、初回一度だけの開始、REPLAY、ONCEの再監視、数字ロールのタイマー解除、画像読み込み、動きを減らす設定、監視非対応時を検証する。掲載13例もサイト固有の関数なしで初期化・動作することを確認する。
- `npm run check`へ同検証を組み込み、既存のTEXT-EFFECT回帰検証とともに実行する。
- 実ブラウザで修正対象のスクロール到達、途中状態、REPLAY、内部スクロール・ページスクロールを確認済み。内部をスクロール済みの演出も、ページ上で画面外へ移るとREPEATの表示状態が解除されること、ONCEのREPLAY後に途中状態が再表示されることを確認した。
- 掲載コード13例をサイトCSS・JSを使わない単独ページでも操作確認した。両詳細ページのCOPY計74件の完了表示、KEYWORDSの絞り込み／解除、ブラウザコンソールのエラーなしを確認済み。COPYのクリップボード内容の一致を実機で検証したという意味ではない。
- SP390pxで全修正対象を操作し、320px・1024px・1440pxでも数値ロールと順次出現の途中状態、ページ・コード枠の横溢れなしを確認済み。`check`・`check:detail`・Fixtureの`build`を実行する。iPhone実機の検証とは区別する。

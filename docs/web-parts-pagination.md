# PAGINATIONの設計

`web-parts/pagination.html`をページ送り専用のカテゴリとして追加する。パンくずリストと同じヘッダー、KEYWORDS・検索、デモ、掲載コード、用途、共通スタイル、フッターの構成を使う。

## 調査と分類

公式デザインシステムで扱う番号指定・省略・前後移動と、検索・管理画面・記事末尾の用途をもとに、6パターンへ整理する。特定サイトの作例を全件移植する構成ではなく、MARK BENCHの用途別分類として再設計する。

| 系統 | パターン | 主な用途 |
| --- | --- | --- |
| NUMBER / 01 | 基本の番号リンク | ページ数が少ない記事・商品一覧 |
| NUMBER / 02 | 両端を残して中間を省略 | 多数の検索結果やカタログ。SPでは近傍番号も減らす |
| COMPACT / 01 | 前後リンクと現在位置 | 小さな画面、前後への閲覧を優先する一覧 |
| COMPACT / 02 | 先頭・末尾へ移動 | 履歴や管理画面。先頭・末尾へ直接移動する操作 |
| CONTEXT / 01 | 表示範囲と総件数を併記 | 検索結果、業務データ。最終ページの端数件数も表示 |
| CONTEXT / 02 | 記事タイトル付き前後リンク | ブログや連載の記事末尾 |

色・角丸だけのバリエーションは独立パターンへ増やさない。無限スクロールと「もっと見る」は内容追加のUI、フォームの進行はステップUIとして区分し、このページへ含めない。ページサイズ選択や任意番号への入力ジャンプはフォーム処理を伴うため、今回の基本的な移動用途には含めない。

## 参照した公式ガイド

- [GOV.UK Design System — Pagination](https://design-system.service.gov.uk/components/pagination/)：検索結果等のページ分割、番号・省略、前後移動、現在ページの意味付け、単一ページではページ送りを出さない考え方を参照する。
- [USWDS — Pagination](https://designsystem.digital.gov/components/pagination/)：有限ページ群の先頭・末尾・現在位置、限られた横幅での番号と省略表示を参照する。
- [Bootstrap — Pagination](https://getbootstrap.com/docs/5.3/components/pagination/)：ナビゲーションのラベルと現在位置、非活性リンクを`span`へ置き換えてフォーカス対象から外す方法を参照する。BootstrapのCSS・JavaScriptへは依存しない。

## 動作と掲載コード

- 外部ライブラリを使わない。メタ情報は`TYPE: CSS + JS`、`DEPENDENCY: NONE`とする。
- 各デモはサンプルのページ範囲または記事名を切り替える。本番の検索API、一覧データ取得、記事へのルーティングは含まない。
- ナビゲーションは`nav`でラベルを付け、番号群はリストで構成する。移動先は`href`を持つリンク、現在位置は`aria-current="page"`を持つ要素、存在しない移動先は`aria-disabled="true"`を持つ非リンクとする。省略記号は操作対象にしない。
- 通常クリック・Enterでは表示とURLを更新し、現在位置へフォーカスを移す。記事型では更新した記事名へフォーカスを移す。フォーカス時にページ全体を強制スクロールさせない。修飾キー付きリンク操作はブラウザの標準動作を維持する。
- URLクエリのキーにはコンポーネントID（`pagination-numbered`等）を使う。他の検索条件・デモの状態を保ち、再読み込みとブラウザの戻る・進むで表示を復元する。不正値・範囲外のページ指定は1ページ目として扱う。
- 掲載HTML・CSS・JavaScriptには単独動作に必要な処理をすべて含める。コピー先で実データへ接続する場合は、サンプル表示の更新処理を一覧更新に置き換え、ID・URL設計をサイトに合わせる。
- プレビューは既存の共通高（PC・小型ノートPC `13rem`、SP `11rem`）へ揃える。コードは3言語を掲載し、2列のPC表示・SPでは3段、1列の小型ノートPCではHTML/CSSの2列とJSの全幅にする。共通スタイルの高さはPC `36rem`、SP `32rem`を維持する。

## 検証項目

- 全デモの番号・前後・先頭・末尾移動と非活性状態、記事名、表示件数の端数、SPの省略表示
- URLへの状態反映、他のクエリ保持、再読み込み、戻る・進む、不正値の扱い
- Tab/Enter、フォーカス、現在位置の意味付け、非活性要素がTab対象外であること
- KEYWORDS・日本語/英語検索・0件表示、全コードのCOPYと掲載内容の一致
- 1440px・1024px・390px・最小320pxでの高さ、横溢れ、見切れ、SPのコード折り返し
- 掲載コードだけの独立ページでの動作、構文、`check`・`check:detail`・`build`、一覧カードと集計件数

## 検証結果（2026-11-07）

- 1440px・1024px・390px・320pxで全デモの領域、共通高、見切れ・横溢れ、SPコードの折り返しを確認。
- 全6種のページ移動と境界状態、記事名、最終ページの端数件数、URL保持・再読み込み・戻る／進む、不正値を1ページ目として扱う動作を確認。
- Enterでの移動とフォーカス表示、非活性要素が非リンクかつTab対象外であること、KEYWORDS・日本語／英語検索・0件表示、全19コードブロックのCOPY内容を確認。
- サイトの共通CSS・JavaScriptを読み込まない独立ページへ、掲載コードをそのまま配置して全6種の操作を確認。
- 一覧カード・CATEGORY・集計、COMMON STYLE・PAGE TOP・BACK TO WEB PARTS、コンソールエラーがないことを確認。
- `npm ci`・`sync:head`・JavaScript構文チェック・`check`・`check:detail`・`build`に成功。掲載HTML/CSSとデモの一致、掲載JavaScriptの構文、詳細ページ数と一覧の合計パターン数の整合性も確認。
